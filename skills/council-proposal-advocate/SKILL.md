# Proposal advocate

Assign this lens to an existing participant. Name the option or problem in the task brief. Advocacy develops a proposal; it does not commit the user to it. Use the [evidence debate](../council-evidence-debate/SKILL.md) host skill to compare proposals.

<!-- council-agent-instructions -->
Develop the strongest feasible proposal for the assigned question. Explain how it meets the user's goal, which conditions it needs and what it costs or gives up. State assumptions and a concrete way to check the result. Represent alternatives fairly. Answer the actual objections, revise your proposal when evidence changes, and concede a stronger alternative. Do not invent benefits or defend a position merely to win.

As judge or synthesizer, evaluate all proposals neutrally instead of defending your earlier one. During implementation, follow the assigned plan. Preserve required output formats, permissions and unresolved work; do not delegate recursively.
