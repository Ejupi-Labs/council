# Managed execution acceptance quickstart

Planned procedure, not passed evidence. Use disposable Git projects, private isolated homes,
fixed local fake scenarios and native process fixtures. Never run an installed provider agent.

## Preparation and ordinary start

Build with npm run build; run npm test and npm run check. Start a private UI owner and open a
fixture with different HEAD/staged/working versions plus ordinary untracked source. Capture its
original bytes, index and branch. Native provider discovery remains unverified during these tests.

Use tasks start with project/text and explicit --fake. Verify one admitted Task/version/Attempt,
visible Fake mode, captured policy and finite deadline. No model/transport form. A second client
reads the same IDs; a repeated request ID replays the original receipt without another invocation.
Different input under that ID conflicts. An unavailable native pin/supervision requirement blocks.

## Source, output and versions

Inspect the fake's actual managed working folder: current source bytes and meaningful staged index
match the source, selected subfolder maps correctly, original files/index/branch remain unchanged.
Hook/fsmonitor/clean-smudge/external-diff sentinels stay untouched during capture. Unsupported
source/index states and oversize inputs block specifically with no older clean-base substitution.

Return a candidate, then inspect exact full response and source-relative delta. Pre-existing dirty
changes are excluded from that delta. It says Verification pending, not accepted/integrated.
Partial-failure output remains available with failed outcome. Query complete bounded artifacts
across Unicode byte boundaries using fixed through/decimal cursors, with no skipped bytes.

Update queued guidance, then release capacity: obsolete version never launches. Existing terminal
attempts remain immutable after an explicit new execution. Global preference changes alone do not
rewrite captured policy. A stale direct expectedPolicyRevision rejects before admission.

For response-only fake work with no changes/outstanding checks, inspect and explicitly accept the
exact current-version response/hash. Stale/wrong/corrupt/incomplete evidence cannot be accepted.
This optional preview path does not fake deterministic checks or imply permanent manual gating.

## Native ownership and faults

Windows fixtures write a first-instruction marker/spawn a child already inside the owned job.
Verify restricted handle inheritance, root/descendant exit and ActiveProcesses=0. Kill owner at
launch/handle boundaries: kernel cleanup attempt occurs, restart retains interrupted uncertainty.

Unix fixtures prove READY/GO, owner EOF, descendant/root ordering, ignored TERM and bounded KILL.
Final negative-PGID signals precede guardian reaping; post-reap reuse permits conservative blocking
only and never another signal. Escaped groups demonstrate declared scope limits and unresolved
known work. Cross-compilation alone is not this native evidence.

Race Stop against dispatch, primary failure and late success. Stop acknowledgement shows Cancelling
until scoped cleanup/drain settles; within15seconds show verified settlement or retained blocker.
Earlier failure remains primary. Unknown cleanup holds capacity. No stale-PID termination.

Inject pre-launch rollback: no worker. Inject post-launch persistence, artifact flush, protocol,
output-limit and drain faults: retain obtained evidence, mark missing portions and fence conflicting
dispatch. No missing output is recreated with another model call. Crash/restart preserves terminal
records and leaves unfinished ownership interrupted, with zero automatic replay.

## Continuing owner, UI and package

Start asynchronously from CLI without a UI owner, close that client and connect from another:
same owner/task continues. Two fresh clients converge on one owner/one shared active slot. Browser
close and wait timeout do not Stop. Explicit service stop closes admission and reports cleanup;
a replayed old shutdown receipt cannot stop a newer owner.

Use the real browser to Start from edited saved draft, lose save/start replies, type newer text,
refresh/switch tasks and reconcile: clicked intent/pending IDs survive and no duplicate starts.
Verify keyboard Start/Stop/details,360px layout, English state labels and unchanged brand identity.

Build/extract native preview from another working directory with no development tools. Run the
existing foundation and new explicit fake journey, inspect package/state exclusions and record
actual app/SQLite/OS/browser versions. Repeat native CI across six targets and supported race.
Write acceptance.md/review.md with observed outcomes, closed findings and unperformed live tests.
